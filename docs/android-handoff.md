# stay calm! · 안드로이드 이식 명세 1.3 · 빌드 4

## 재사용할 파일

| 파일 | 역할 |
| --- | --- |
| web/index.html, style.css | 화면 뼈대, 색상·간격·유리 버튼·표시 효과 |
| web/app.js | 메뉴, 참기, 기록, 주간 통계, 시간표 등록, 가져오기 확인, 설정 |

이 버전은 화면과 저장·통계 로직을 기기 안의 웹뷰에서 실행한다. Android에서는 같은 web 폴더를 앱 assets로 넣고 WebViewAssetLoader 등을 사용해 고정된 로컬 출처로 로드한다. JavaScript와 DOM 저장소를 켜고, release 빌드에서 앱 재실행·업데이트 후 데이터가 유지되는지 확인한다. Android 네이티브 래퍼 및 APK는 추후 작업이다.

색상·수치의 기준 파일은 style.css이다. Android에서 웹뷰를 유지하면 UI를 다시 구현할 필요가 없다. 상태 표시줄·시스템 내비게이션을 고려하고, OS 뒤로가기는 열린 대화상자 또는 메뉴부터 닫도록 연결한다.

## 기록 및 콤보

- 기기 현지 시각을 사용한다. 시작 시각은 포함하고 종료 시각은 제외한다. 공강은 ‘수업 외’에 저장한다. 겹치는 수업은 탭 시 사용자가 선택하며 첫 탭의 시각으로 저장한다.
- 1탭은 1회다. 같은 날짜·수업에서 이전 입력과 900ms 이내이면 콤보가 이어지고 3회째부터 숫자와 붉은 광채를 표시한다. 마지막 입력 약 920ms 후 표시가 사라진다. 최대 배경 불투명도는 0.22다.
- 효과를 끄면 콤보 숫자와 파동·배경 효과를 숨긴다. 시스템 동작 줄이기는 파동·버튼 축소·붉은 빛을 줄인다. 화면이나 수업 전환, 앱 백그라운드 이동 시 콤보를 초기화한다.
- 실제 탭 시각에 현재 수업을 다시 계산한다. 순위는 수업 안에서 발생한 입력만 사용하며 수업 외 건수는 별도 표시한다. 동점은 공동 순위다. 누른 횟수는 사용자의 주관적인 지표다.

## 데이터 형식

웹 저장소 키는 staycalm.v1. 접두사로 시작한다. 하나의 날짜 기록을 JSON 배열로 저장해 빠른 입력 시 순서대로 반영한다. 저장 실패 시 알림을 표시한다.

| 키 (접두사 생략) | 내용 |
| --- | --- |
| slots | 수업 배열. id는 UUID, name은 과목명, weekday는 일=0~토=6, start/end는 자정 이후 분 |
| day.YYYY-MM-DD | 입력 배열. id, at(유닉스 밀리초), day(현지 날짜), hour(0~23), clock(HH:mm), slot |
| 각 입력의 slot | 해당 시점의 id/name/start/end 사본 또는 수업 외이면 null |
| settings | haptics와 effects 불리언. 각 기본값 true |

같은 이름을 가진 과목의 주간 횟수는 합산한다. 날짜별 상세 내역은 당시 수업 ID와 이름·시간으로 구분하므로 시간표 수정 전 기록도 유지된다. 백업·복원, 학기별 시간표, 날짜 한정 휴강/보강, 시간당 보정 점수는 1.1에 포함하지 않았다.

## 플랫폼 연결

- iOS가 선택한 사진 한 장을 방향 보정하고 긴 변 최대 2200px로 축소한다. Vision의 정확도 우선 모드와 ko-KR/en-US로 인식한다. 화면에 이미지와 OCR 결과만 전달한다. 앱은 원본 캡처를 파일로 보관하지 않는다.
- JS 공통 입구는 receiveTimetable(dataURL, words)이다. 각 단어는 {text, x, y} 구조이고 x/y는 왼쪽 위 기준 0~1의 중심 좌표다. Android는 시스템 사진 선택기와 한국어를 지원하는 기기 내 OCR을 이 입구에 연결하면 된다. 진동은 기존 iOS 브리지 호출 위치에 Android의 가벼운 탭 피드백을 연결한다.
- 요일 경계인 세로선과 일정 간격의 가로 눈금을 함께 찾고, 왼쪽 시간 열의 숫자 여러 개로 첫 시각을 추정한다. 자동 인식 화면에서 첫 시각을 확인·수정할 수 있다. 표를 찾지 못하거나 사용자가 범위를 다시 지정하면 원래의 두 점 지정 방식을 사용한다.
- 각 요일의 30분 구간에서 여러 지점의 색을 조사해 다수인 채색을 사용한다. 붙은 구간의 색이 바뀌면 수업을 나눈다. 인식·직접 등록·수정은 00분과 30분을 기본 선택지로 사용한다. 이전 데이터의 분 단위 시각은 해당 항목에만 선택지로 보존한다.
- iOS는 courseNames 브리지로 각 수업 칸의 정규화 사각형을 받아 그 부분만 다시 OCR한 뒤 receiveCourseNames(token, groups)에 전달한다. 그룹의 각 줄에는 text, x, y, h가 들어가며 좌표와 글자 높이는 잘라낸 칸 기준이다. 과목 줄을 합치고 강의실 패턴이나 글자 크기 차이에서 중단한다. 사용자가 저장하기 전 이름·요일·시간을 검토한다.
- 같은 색으로 연달아 배치된 수업, 무채색 테마, 작은 이름, 여러 줄 과목명에서는 수동 수정이 필요할 수 있다. 사용자가 확인 후 저장해야 반영된다. 에브리타임 계정 로그인, 공유 링크 동기화, 외부 OCR 전송은 구현하지 않았다.
- 외부 웹사이트를 로드하지 않는 앱 내부 웹뷰에서만 네이티브 브리지를 제공한다. Android 릴리스 테스트는 ① 기기 재시작 후 기록 복구 ② 연타 ③ 수업 종료 정각 ④ 일·월 경계 ⑤ 겹치는 수업 ⑥ 캡처 한 장의 선택·취소·수정 저장 ⑦ 폰트 확대·뒤로가기 순으로 진행한다.

## 빌드 3 · 입력과 콤보 연출

실제 버튼은 원의 지름에 좌우·상하 각각 18~32 CSS px의 여백을 더한 사각형이다. 아이콘의 표시 크기는 종전과 같다. 탭 시 3콤보부터 시계 방향으로 이동하는 원주 접촉점에서 접선 속도 (−sin θ, cos θ)와 작은 바깥쪽 속도를 합쳐 불티를 방출한다. 콤보에 따라 접촉점·입자 수가 늘어나고 최대 220개로 제한한다.

100회, 그리고 500회부터 매 500회째에 글자만 680ms 동안 세로축으로 두 바퀴 회전하며 위로 떠오른다. 650ms에 금색·주황·분홍 불꽃과 정확한 달성 횟수가 나타난다. 축하 중에도 버튼은 입력을 받는다. 900ms 연타 제한과 1탭 1회 기록을 유지한다. 효과를 끄면 시각 연출을 생략하며 동작 줄이기에서는 달성 문구만 표시한다. web/effects.js와 web/style.css를 함께 사용한다.

## 빌드 4 · 원 둘레 전체 스파크

3콤보부터 원주 중 min(콤보/50, 1) 구간을 시계 방향으로 밝힌다. 25콤보는 반원, 50콤보 이상은 360도다. 밝은 중심선과 주황색 광채를 겹치고, 55ms 간격으로 최대 40개 접촉점에서 접선 방향으로 불티를 발사한다. 콤보 타이머가 끝나면 원주와 발사를 멈추고 남은 입자만 소멸한다. 효과 끄기 및 동작 줄이기 설정을 따른다.
