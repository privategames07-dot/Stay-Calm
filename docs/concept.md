# stay calm! — iPhone 앱 콘셉트

> 수업 중 참을 때마다 누르는 버튼. 오늘 얼마나 참았는지 기록하고, 이번 주 어떤 수업과 시간이 가장 빡셌는지 돌아보는 앱.

- 문서 작성일: 2026-11-13
- 앱 이름: **stay calm!**
- 대상: iPhone
- 문서 범위: 앱 콘셉트와 주요 동작 정리. 실제 구현이나 연동 가능 여부를 확정하는 문서는 아님.
- 아래에서 **핵심 구상**은 사용자가 제시한 내용이며, **설계 제안**은 구현을 위해 덧붙인 초안임.

## 1. 핵심 구상

수업 시간표를 등록해 두고, 수업 중 힘들거나 참아야 할 때 중앙의 `忍` 버튼을 누른다. 앱은 버튼을 누른 날짜와 현재 시각을 시간표와 대조해 **해당 날짜의 해당 수업에 누른 횟수를 자동으로 저장**한다.

나중에 날짜별 기록과 주간 통계를 보면서 어떤 수업이 가장 빡셌는지, 어느 시간대에 가장 많이 눌렀는지 확인한다. 연속으로 누르면 콤보와 붉은 이펙트가 활성화돼 누르는 재미도 느낄 수 있다.

시간표는 매번 직접 입력하기보다 **에브리타임(Everytime)에서 가져오는 방식**을 우선한다.

## 2. 디자인

### 핵심 구상

| 요소 | 디자인 방향 |
| --- | --- |
| 배경 | 깨끗한 흰색 |
| 메인 버튼 | 화면 중앙에 크게 배치한 유리 느낌의 원 |
| 버튼 글자 | 원 중심에 큰 빨간색 볼드체의 **忍** |
| 기본 분위기 | 여백이 많고 단순한 화면 |
| 연속 입력 상태 | 콤보 표시와 배경의 붉은 이펙트 |

### 설계 제안

- 유리 원에는 반투명한 표면, 가장자리의 빛 반사, 은은한 그림자를 적용한다.
- 터치하면 원이 살짝 눌렸다 돌아오고, 표면에 짧은 파동이 퍼진다.
- 평상시에는 흰 배경을 유지하고, 연속 입력할수록 붉은 빛이 점차 강해지도록 한다.
- 효과가 강해져도 `忍`, 현재 수업명, 횟수는 계속 읽을 수 있어야 한다.
- 수업 중 사용할 앱이므로 소리는 기본적으로 끄고, 진동과 화면 효과는 선택할 수 있도록 한다.

## 3. 기본 사용 흐름

1. 에브리타임 시간표를 가져온다.
2. 가져온 과목명·요일·시작 및 종료 시각을 확인하고 저장한다.
3. 앱을 열면 현재 시간에 해당하는 수업이 표시된다.
4. `忍` 버튼을 누르면 해당 날짜의 수업 기록에 1회씩 쌓인다.
5. 계속 누르면 콤보와 붉은 효과가 나타난다.
6. 기록 화면과 주간 통계에서 지난 내용을 확인한다.

위 흐름은 핵심 구상이며, 가져오기 확인 화면과 세부 표시 방식은 설계 제안이다.

## 4. 시간표 가져오기

### 핵심 구상

**에브리타임에 만들어 둔 시간표를 가져와 사용한다.** 시간표를 앱에서 처음부터 다시 만드는 번거로움을 줄인다.

### 설계 제안: 가져오기 방식

| 우선순위 | 방식 | 동작과 검토 사항 |
| --- | --- | --- |
| 우선 검토 | 시간표 공유 링크 | 에브리타임에서 복사한 시간표 링크를 붙여넣어 수업 정보를 가져온다. 접근 조건과 실제 가져오기 가능 여부를 개발 전에 확인한다. |
| 대안 | 시간표 이미지·스크린샷 | 사용자가 선택한 시간표 이미지에서 과목명과 시간대를 인식한다. 인식 결과는 사용자가 수정한 뒤 저장한다. |
| 보완 | 직접 입력·수정 | 가져오기가 실패하거나 일정이 달라졌을 때 과목과 시간을 직접 수정한다. |

이미지 방식에서 사용하는 OCR은 이미지 속 글자를 읽는 기능이다. 글자 인식뿐 아니라 시간표의 요일·시간 축과 수업 블록을 함께 해석해야 하며, 잘린 이미지나 작은 글자 등으로 잘못 읽을 수 있다.

### 가져온 뒤 확인할 정보

- 학기 또는 시간표 이름
- 과목명
- 수업 요일
- 시작 시각과 종료 시각
- 같은 과목의 여러 수업 시간

### 연동 관련 확인 사항

- **에브리타임에서 가져오기**와 **시간표 변경 사항의 실시간 자동 동기화**는 별도 기능으로 다룬다.
- 첫 버전은 사용자가 가져오기를 실행해 앱에 저장하는 방식을 제안한다.
- 공유 링크를 쓰는 타 서비스 사례는 있지만, 이 앱에서도 같은 방식으로 작동한다는 보장은 없다.
- 공개 API(외부 앱이 공식적으로 데이터를 주고받는 연결 수단)의 제공 여부와 사용 조건은 확인이 필요하다. 공식 연동이 확정됐다고 가정하지 않는다.
- 앱에서 에브리타임 아이디나 비밀번호를 직접 입력받는 방식은 초기 설계에 포함하지 않는다.

## 5. 수업 자동 배정과 기록

### 핵심 구상

버튼을 누르는 순간의 날짜·요일·시각을 확인해, 시간표상 진행 중인 수업에 횟수를 저장한다. 같은 과목이라도 날짜가 다르면 각각의 수업 기록으로 남는다.

예를 들어 월요일의 같은 과목을 11월 16일에 8번, 11월 23일에 15번 눌렀다면 두 날짜의 기록을 따로 확인하고, 주간 통계에서는 해당 주의 기록만 합산한다. 날짜와 횟수는 동작 설명을 위한 가상 예시다.

### 설계 제안: 세부 규칙

| 상황 | 제안 동작 |
| --- | --- |
| 수업 진행 중 | 해당 날짜의 수업에 자동 저장 |
| 수업 시작 시각 | 시작 시각부터 해당 수업에 배정 |
| 수업 종료 시각 | 종료 시각은 제외하고, 그 시각에 시작하는 다음 수업이 있으면 다음 수업에 배정 |
| 공강·수업 외 시간 | 특정 과목에 넣지 않고 ‘수업 외’로 별도 저장 |
| 시간이 겹치는 수업 | 저장할 수업을 선택하게 하고 임의로 배정하지 않음 |
| 휴강·보강·시간 변경 | 해당 날짜의 일정만 수정할 수 있도록 함 |
| 시간표 수정·재가져오기 | 기존 기록의 수업명과 날짜는 유지하고, 새로운 일정부터 반영 |
| 빠른 연속 입력 | 정상 입력을 빠뜨리지 않고 실제 누른 횟수만큼 저장 |
| 앱 종료 후 재실행 | 이전에 저장한 시간표와 기록 유지 |

버튼을 누른 시각을 개별 기록으로 남겨야 나중에 수업별 합계뿐 아니라 시간대별 통계도 만들 수 있다. 최소 기록 정보는 누른 시각, 연결된 과목, 해당 날짜의 수업 시작·종료 시각이다. 콤보 통계를 넣는 경우 콤보 관련 정보도 함께 보관한다.

## 6. 콤보와 붉은 이펙트

### 핵심 구상

버튼을 계속 누르면 **Combo가 활성화**되고, **배경에 붉은 이펙트**가 나타난다. 단순히 횟수만 증가하는 화면보다 누를 때마다 반응이 있는 화면을 지향한다.

### 설계 제안: 동작 초안

| 상태 | 화면 반응 |
| --- | --- |
| 한 번 누름 | 원이 눌리는 애니메이션과 짧은 파동 |
| 연속 입력 | 버튼 주변에 콤보 숫자 표시 |
| 콤보 증가 | 붉은 광채와 배경 효과가 점차 강해짐 |
| 입력 중단 | 일정 시간이 지나면 콤보 종료, 기본 화면으로 복귀 |

- 콤보 인정 간격과 발동 횟수는 직접 눌러 보며 정한다.
- 콤보는 시각적 보상으로 사용한다. **실제 기록 횟수는 터치 1회당 1회**로 유지하는 것을 제안한다.
- 효과의 강도에는 상한을 두고, 빠른 점멸 대신 부드러운 빛과 파동을 우선한다.
- 콤보가 끝나도 이미 쌓인 수업 기록은 유지한다.
- 진동과 움직임 효과를 줄이거나 끌 수 있도록 한다.

## 7. 화면 구성

아래는 핵심 기능을 담기 위한 화면 구성 제안이다.

### 메인 화면

- 상단: 현재 수업명과 수업 시간
- 중앙: 유리 느낌의 큰 원형 `忍` 버튼
- 버튼 주변: 입력 직후의 반응과 콤보 표시
- 하단: 이번 수업에서 누른 횟수
- 이동 메뉴: 참기 / 기록 / 통계 / 시간표

### 기록 화면

- 날짜를 선택해 그날의 수업 목록을 확인한다.
- 각 수업에서 누른 횟수를 표시한다.
- 같은 과목의 다른 날짜 기록도 찾아볼 수 있도록 한다.
- 상세 화면에서는 언제 많이 눌렀는지 확인할 수 있도록 한다.

### 주간 통계 화면

- 주를 선택해 해당 주의 기록을 확인한다.
- **어떤 수업이 가장 빡셌는지** 과목별 누른 횟수로 보여준다.
- **어떤 시간이 가장 빡셌는지** 시간대별 누른 횟수로 보여준다.
- 순위와 간단한 그래프를 사용하고, 정확한 횟수를 함께 표시한다.

### 시간표 화면

- 에브리타임 시간표 가져오기
- 가져온 수업 확인·수정
- 주간 시간표 확인
- 필요 시 다시 가져오기

## 8. 주간 통계 기준

**수업별·시간대별 주간 통계는 핵심 구상**이며, 아래의 계산 기준과 보조 지표는 제안이다.

| 지표 | 계산·표시 기준 |
| --- | --- |
| 이번 주 총 참은 횟수 | 선택한 주의 수업 기록 합계 |
| 가장 빡셌던 수업 | 해당 주에 가장 많이 누른 과목 |
| 가장 빡셌던 시간대 | 해당 주에 가장 많이 누른 시간 구간 |
| 날짜별 수업 기록 | 과목과 실제 수업 날짜를 함께 표시 |
| 보조 지표: 수업 1시간당 횟수 | 과목별 횟수를 비교 대상 수업 시간으로 나누어 긴 수업과 짧은 수업 비교를 보완 |

- 주간 범위는 월요일부터 일요일까지로 제안한다.
- 시간대는 우선 1시간 단위로 제안하며, 실제 누른 시각을 기준으로 묶는다.
- 수업 외 기록은 별도로 표시하고 수업 순위에서는 제외한다.
- 같은 횟수는 공동 순위로 처리한다.
- 기록이 없으면 ‘가장 빡센 수업’을 임의로 선정하지 않는다.
- ‘빡셌다’는 사용자가 누른 횟수를 재미있게 표현한 것으로, 실제 강의 난이도나 스트레스의 객관적 측정값은 아니다.
- 보조 지표를 도입할 경우 휴강·결석 등 비교에 포함할 수업 시간의 기준을 먼저 정한다.

## 9. 첫 버전 제작 범위 제안

### 우선 구현

- 흰 배경, 유리 느낌 원형 버튼, 큰 빨간색 볼드체 `忍`
- 시간표 저장과 현재 수업 자동 판별
- 날짜별·수업별 버튼 기록 저장
- 에브리타임 시간표 가져오기: 링크 방식 가능 여부를 먼저 확인하고, 어려우면 이미지 가져오기와 확인·수정 흐름을 구현
- 날짜별 기록 조회
- 과목별·시간대별 주간 통계
- 기본 콤보와 붉은 배경 효과

### 이후 확장 후보

- 더 다양한 콤보 효과와 진동 패턴
- 일별·월별 통계
- 기록 수정과 실수로 누른 입력 취소
- 기록 내보내기와 기기 변경 시 복원

확장 후보는 원래 요청에 포함된 확정 기능이 아니며, 첫 버전이 완성된 뒤 선택한다. 초기에는 로그인 없이 기기에 기록을 저장하는 방향을 제안한다.
